
# 📝 Post Maker App

A simple **Post Maker Web Application** where users can **login, create posts, style their posts, edit, delete, and view posts from other users**. This project demonstrates CRUD operations, authentication, and dynamic UI styling.

---

## 🚀 Features

* 🔐 **User Authentication**

  * Users can login to access the application.

* ✍️ **Create Posts**

  * Users can create their own posts.

* 🎨 **Style Posts**

  * Customize:

    * Text color
    * Background color

* ✏️ **Edit Posts**

  * Users can update their existing posts.

* 🗑️ **Delete Posts**

  * Users can remove their posts anytime.

* 🌍 **View Other Users' Posts**

  * Users can see posts created by others in the feed.

---

## 🛠️ Technologies Used

* **Frontend**
  * Tailwind CSS
  * javascript


## 📸 Application Flow

1. User logs into the application.
2. User creates a post.
3. User can style the post (text color & background color).
4. The post appears in the main feed.
5. User can edit or delete their post.
6. All users can view posts created by others.
